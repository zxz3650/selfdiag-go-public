# selfdiag-go

Linux·macOS의 조사 자료를 수집하고, 수집 상태와 무결성을 검증한 뒤 탐지 결과를 보고하는 Go 도구입니다. 수집 실패를 정상 상태로 바꾸지 않도록 파일별 상태를 기록합니다.

## 구현 범위

- 기본·확장 프로파일에 따라 호스트 자료를 수집하고 manifest에 파일별 결과를 남깁니다.
- SHA-256으로 수집물의 변경 여부를 확인합니다.
- Linux 로그의 로그인 실패, 지속성 등록, 스캔 도구 실행 흔적을 탐지합니다.
- `matched`, `unknown`, `skipped`를 구분하고 근거 파일과 행을 보고서에 연결합니다.
- JSON·HTML 보고서를 생성합니다.

`unknown`은 자료 부족 또는 수집 실패를 뜻하며 안전 판정이 아닙니다. 브라우저 이력, 환경변수, 실행파일 등 민감도가 높은 추가 수집은 명시적으로 켜야 합니다. 이 도구는 수집된 증거에 한해서만 판단합니다.

## 로컬 검증

Go 1.24 이상에서 다음 명령을 실행합니다.

```bash
go test ./...
go vet ./...
sh scripts/build.sh
```

2026-11-16에 `go test ./...`와 `go vet ./...`를 통과하고 Linux·macOS 빌드를 확인했습니다. 테스트 입력의 IP와 로그는 문서용 합성 값입니다. 실제 사고 자료나 자격증명은 포함하지 않습니다.

## 코드 길잡이

- `internal/collector`: 플랫폼별 수집 정의와 파일별 상태 기록
- `internal/evidence`: manifest와 해시 검증
- `internal/detector`: Linux 로그 규칙과 판정
- `internal/report`: JSON·HTML 결과 출력
- `profiles`: 운영체제별 확장 수집 프로파일

원본 분석 자료와 실행 결과는 이 공개 저장소에 포함하지 않습니다.
